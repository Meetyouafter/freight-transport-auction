## Быстрый старт

```bash
npm install
npm run dev
```

Dev-сервер автоматически поднимает MSW-воркер (`src/mocks`).
Реализует `src/mocks/openapi.auctions.v0.json`: `POST /auctions/list`, `GET /auctions/{auctionUuid}`,
`GET /auctions/{auctionUuid}/bets`, `POST /auctions/{auctionUuid}/bets`.

## Проверка работы приложения

1. Запустить дев-сервер и открыть сайт в браузере:

- проверить отображение списка аукционов
- проверить фильтры
- проверить пагинацию
- проверить детали аукциона
- проверить ставку и валидацию
- проверить ставки на повышение и понижение
- проверить недоступность действий закрытого аукциона
- проверить визуал ставок и уведовления
- проверить шаг ставки и валидацию
- проверить установку и отображение ставки

2. Прогнать тесты:

   ```
   npm run test
   ```

3. Проверить типы и линтеры:

   ```
   npm run typecheck
   npm run lint
   ```

4. Убедиться, что собирается прод-сборка:
   ```bash
   npm run build
   npm run preview
   ```
